1-다 과제유형을 제안합니다. `[선택지]` 에서 **하나만** 고르고, 고른 이유를 1~2문장으로 씁니다.

- basic(기초연구): 현상·원리 규명, 새로운 지식 확보가 목적인 연구
- applied(응용연구): 기초 지식을 특정 실용 목적(설비·업무)에 적용하는 방법을 찾는 연구
- development(개발연구): 제품·시스템·장치를 만들거나 기존 것을 실질적으로 개선하는 연구
- 판단 기준은 제안자 입력의 "해결 목표"와 결과물의 형태입니다.
- 출력은 `{"choices": ["applied"], "sentences": [...]}` 형태의 객체 하나입니다. `evidence` 는 비워도 됩니다.
