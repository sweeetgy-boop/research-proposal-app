`https://rra.taile5afcf.ts.net` → 127.0.0.1:8000(ADR 0047). 출처 `deploy/README.md`.

**데이터 흐름**(그림 `docs/history/diagrams/02-six-step-flow.svg`·`06-data-boundary.svg`·`07-sources.svg`)
1. 야간 적재: 자료원 → 샌드박스 파싱 → 이름 제거 → SQLite(문서·청크·임베딩), visibility public/internal.
2. ① 정책 근거 추천: 정책 문서 자료원만 검색해 문장 고르기(LLM 없음, 공용 계정은 internal 제외) → 제안자가 [적용]한 것만 정책 근거 칸에.
3. ② 입력 확인: 규칙 판정 표(reranker + 핵심 키워드, 연작 묶기) → 실시간 검색(ScienceON·NTIS·OpenAlex, 결과는 public 으로 DB 저장)
   → Argon 같음 판정 → 제안자 선택 → 차별화 과제안.
4. ③ 생성: 섹션별 검색(근거 구성 규칙 `config/retrieval_mix.yaml`) → Argon 섹션 작성(근거 id 대조) → 규칙 검사 → L2 로컬 2차 검토
   → v1(초안 글 먼저) → 그림 백그라운드.
5. ④~⑥: 직접 수정(버전) → Argon 최종 검토 → HWPX(서식 점검·그림 삽입). 외부 전송은 manifest 에 문서 단위로 기록.

## ⑥ AI 활용 방식

| 역할 | 모델 | 하는 일 | 출처 |
|---|---|---|---|
| Argon(주 작성·판정·검토) | Gemini(`config/llm.yaml providers.gemini`, 모델 이름 `gemini-4-argon`) | ③ 섹션 작성(4 동시), ② 같음 판정·키워드·과제안, 정책 작성안 다듬기, 보강·보완 질문, AI 다시 쓰기, 그림 명세, L2 불일치 문장 수정 제안, ⑤ 최종 검토 | ADR 0032·0036·0037 |
| 로컬 LLM | Qwen2.5-7B-Instruct-4bit(mlx, 127.0.0.1) | Argon 이 **오류로 답할 때만** 대신(호출 실패·교정 뒤에도 형식 오류), L2 로컬 2차 검토(문장이 근거로 뒷받침되는가) | ADR 0038·0040 |
| Nano Banana Pro | `gemini-3-pro-image` | 그림 1회 채택(실패면 SVG 기본 그림), 9pt 미달이면 1회 다시 그림, 하루 150장 | ADR 0029·0044 |
| 임베딩·reranker | multilingual-e5-base, bge-reranker-v2-m3(로컬) | 검색·유사과제 판정(reranker ≥ 0.5) | ADR 0013·0036 |
| 판단 | 규칙(LLM 아님) | 흐름 제어·차단 해제·제출 전 점검 | CLAUDE.md "Agent = 규칙 기반" |

이전 방식(지우지 않고 표시): 2026-10-28 오후까지는 로컬 7B 가 주 작성자였고 Argon 이 ③ 1차 검토(v1→v2)를 했다(ADR 0007). 7B JSON 실패
4/10·한 건 155초 때문에 Argon 먼저로 바꿨다(ADR 0032). 1차 검토는 자기 검토가 되어 끄고 L2 로컬 2차 검토로 대신했다.

**지어내기(할루시네이션) 방지 장치**
- 근거 id 대조: 문장마다 근거 id, 검색 집합 밖 id 는 폐기(보안 A, `domain/rules/grounding.py`). LLM 출력은 JSON 만 파싱.
- 관련도 하한: 코사인 ≥ 0.79 + 한글 청크는 질의 키워드 ≥ 1, 통과 0 이면 빈칸 + 알림(ADR 0005).
- 정책·수치: 정책·계획명은 입력·근거에 있는 것만, 입력·근거·표 칸(table_facts)에 없는 수치는 알림 + 검토 지적 의무(ADR 0022).
- 정책적 중요도: 제안자가 적거나 [적용]한 정책 근거만 근거로 쓴다(추천 1순위도 미리 체크일 뿐 자동으로 넣지 않음, ADR 0040·0052). 작성안은 정책 문서 인용 구간 안에서만, 고른 안은 원문 재대조 뒤 그대로, 없으면 "정책 근거 확인 필요"(ADR 0037).
- 근거 범위: 2-가-(3) 경영전략 정합성은 정책 문서만(행정 공시·현황·통계 제외, ADR 0046).
- L2 로컬 2차 검토: 문장별 지지·부분·불일치 + 규칙(근거에 없는 수치·이름), 불일치만 Argon 수정 제안, 자동 반영 없음(ADR 0040).
- 그림: 명세 글자는 본문·입력·검증된 근거·표 칸만, 그림은 제안자가 [확인함](ADR 0029).
- 빈 결과 금지: 빈 문장 목록은 실패로 보고 교정 재요청, 실패 섹션은 사유와 [다시 생성](ADR 0027·0037).
