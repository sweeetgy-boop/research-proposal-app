- **Mi:dm**: 지시한 출력 모양을 거의 지키지 않았다. 비선택 섹션에서 `{"choices": [...], "sentences": [...]}` 선택형 모양을 내고(관용 처리로 1건만 회수), 제목은 배열이 아닌 객체 하나, 근거 id 를 `<doc id='basis=abstract'>`·`current_state` 처럼 지어냈다. 응답이 max_tokens(2000)까지 이어져 섹션당 17초(Qwen 6.4초). 24GB 개발기에서는 기본 prefill 2048 로 6K 토큰 프롬프트를 처리하다 Metal 메모리 부족이 1회 났고 `--prefill-step-size 512 --prompt-cache-size 1` 로 재실행했다(32GB Mac mini 에서는 재확인 필요).
- **A.X 4.0 Light**: 빠르고(0.64×) 한국어 문장은 자연스럽지만, 선택형 섹션(task_type·utilization) 6건 모두 `sentences` 가 스키마에 안 맞아 선택지만 살았고(choices_only), method 1건은 JSON 이 아니었다. 근거 대조 폐기 6문장(Qwen 0).
- **Qwen(현행)**: 2차 실행에서 03번(철도 무관 아이디어)의 tech_importance·utilization 이 JSON 이 아니어서 93.1%. 1차 실행(관용 처리 전 코드)은 100%. 폴백은 세 모델 모두 0 (mlx_lm.server 는 response_format 을 조용히 무시하므로 json_mode=prompt).
