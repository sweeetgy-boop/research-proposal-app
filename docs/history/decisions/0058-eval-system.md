# ADR 0058 — 평가 체계 3단계(L0 PR·L1 야간·L2 배포 전)와 봉인 시험 묶음 (2026-11-09 초안, chore/wave-1109-contracts)

## 배경
- 유사과제 판정·과제안 품질은 지금까지 골든셋 10건(`tests/golden`)과 손으로 돌린 측정 문서(`docs/eval-*.md`)로만 봤다.
  10건은 임계치(reranker 0.5·핵심어 1)·풀 크기(7/28)를 정하기에는 됐지만, 검색·판정을 바꿀 때(4축·IDF·동의어, ADR 0059)
  "좋아졌다/나빠졌다"를 신뢰구간 있게 말하기엔 적다. 같은 문제도 Argon 판정이 흔들린다.
- 운영 기록(`similar_choices.jsonl`, `recommend_metrics.jsonl`)이 쌓이기 시작했지만 지표로 묶지 않았다.
- 개선 작업 중에 평가 문제를 보고 맞추면(과적합) 평가가 의미를 잃는다.

## 선택지
1. 골든셋을 30건으로 늘리고 손으로 계속 잰다 — 비용 적음, 신뢰구간 없음, 과적합 방지 없음.
2. **세 단계 평가 + 자동 생성 문제 + 봉인 시험 묶음.** L0(PR 마다, LLM 캐시 재생, 1~2분) · L1(매일 밤, DB 에서 seed 로 100건 이상 뽑아 3회 평균,
   95% 신뢰구간) · L2(배포 전·주 1회, 골든셋 + 초안, 사람 확인 10%). 시험용 묶음은 seed 고정·봉인(개선 중 열람 금지).
3. 외부 평가 도구(LLM-as-judge 전용 서비스) — 외부 전송 범위가 늘고 사내 자료 문제를 보낼 수 없다.

## 결정
2 를 택한다.
- 결과 형식은 `domain/models/eval_result.py`·계약 `docs/contracts/eval-results.md` 하나. 지표 7개(recall_at5·false_block·novel_rate·
  novel_estimated_barrier_ratio·latency_p50·latency_p90·rec_zero_rate)는 비율·초·건수만 — 문제 본문·식별자는 결과에 넣지 않는다.
- 문제 자동 생성 세 종류: 역방향(실제 과제 → 제목 단어 없는 아이디어, 정답 = 원래 과제), 함정(A 의 대상 × B 의 방법, 차단되면 오답),
  새 영역(novel 갈래가 정답). 매 실행 새 seed, 시험용은 seed 고정·600 권한·`.gitignore`·문서에 "열람 금지" 명시.
- AI 흔들림은 같은 문제 3회 평균 + 95% 신뢰구간으로 적는다. 비교(`rra eval compare`)는 구간이 겹치면 "차이 없음"으로 읽는다.
- 실사용 기록 지표(`rra eval usage`)는 `source=user`·`test` 아님 줄만.
- 평가용 Gemini 호출은 `config/eval.yaml daily_llm_calls` 안에서만 — Argon 잔액(일일 600) 보호.
- L0 는 CI job `eval-l0` 로 PR 마다, 직전 main 결과 대비 recall_at5 −0.05·false_block +0.05 넘으면 실패.

## 이유
- 신뢰구간 없는 단일 수치로 임계치를 바꾸다 거짓 차단(2026-10-28 폐역사 사례)이 나왔던 일을 되풀이하지 않기 위해.
- 봉인 묶음이 없으면 레인 E 같은 개선 작업이 평가 문제에 맞춰질 수 있다.
- LLM 캐시 재생(L0)은 PR 마다 Gemini 를 쓰지 않으면서도 판정 회귀를 잡는다.

## 결과
- 좋은 점: 스위치(ADR 0059)를 켜고 끄는 결정이 같은 seed 의 비교표로 남는다. 운영 기록이 지표가 된다.
- 비용: 야간 L1 10~20분(Gemini ≤150회/일), launchd plist 하나(`com.rra.eval`, 04:30), `eval/results/` 커밋 증가(수치만).
- 남은 것: 지표 임계치(L0 게이트 ±0.05)는 첫 2주 분포를 보고 조정. L2 사람 확인 표본의 기록 방식은 운영 뒤.
- 상태: **확정(2026-11-09 저녁)** — 레인 D 구현(ADR 0063, #139) + 짝 비교·McNemar·갈린 문제만 반복(#141, 사용자 보완). 첫 비교 `docs/eval-2026-11-09-compare.md`. 봉인 묶음 119건 생성(열람 금지). 후속: 함정 생성 보정, `llm_calls` 집계, 예산 카운터 파일 잠금.
