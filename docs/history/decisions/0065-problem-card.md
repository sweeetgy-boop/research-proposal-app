# ADR 0065 — 문제 정의 카드: 제안문을 AI 1회로 진단하고, 유추·과제안을 장소어가 아니라 문제 기준으로 (2026-11-10, feat/problem-card-contract)

## 맥락
- 유추 검색(ADR 0057)은 규칙으로 뽑은 '문제어'에 기댄다. 대상어(비둘기)와 작용·일반 낱말(침입·방지·민원)이 같은 무게라
  "철도역사 비둘기 침입 방지"에서 침입·방지에 끌린 자료(지장물검지장치·비상게이트)가 위에 오고 조류 퇴치 특허·버드넷이 밀렸다.
- 영문 질의는 키워드 호출이 성공할 때만 생겨 OpenAlex 가 0건인 때가 있고, KIPRIS 는 자유 검색만 써서 특허 분류를 활용하지 못한다.
- 2026-11-10 저장 자료 시뮬레이션(읽기 전용): "공유 문제어 수 → 유사도 + 자료원당 2건"만 적용하면 "방지" 하나 겹친 특허(설치류 유인
  미끼장치)·장소어에 끌린 특허(공중화장실 비상벨)·무관한 영문 논문이 자료원 몫으로 들어왔다. 카드의 대상어 겹침 + 기능 문장 재순위는
  비둘기 5건이 모두 조류 접근 차단 자료였고 악취 사례도 나빠지지 않았다(재순위 40건 2.4~4.0초).

## 선택지
1. 장소어 목록(`novelty.yaml place_ko`)만 늘린다 — 작용어·일반어 문제는 남고 사례마다 목록을 고쳐야 한다.
2. 정렬 규칙만 바꾼다 — 위 시뮬레이션대로 오히려 나빠진다.
3. **AI 진단 1회로 '문제 정의 카드'를 만들고 규칙으로 검증한다.** 카드의 기능 문장·사다리·대상어·모순·분류 코드를 유추·과제안·보완 질문이 쓴다.

## 결정
3을 택한다. 계약 `docs/contracts/problem-card.md`.
- **1단계** AI 1회(Argon 먼저, 오류면 로컬): 항목 나누기(현상·대상·장소·원인·피해·원하는 결과), 기능 문장 국·영문(TRIZ 기능 분석,
  장소어 제외), 추상화 사다리 3단, 모순, 근본 원인 2단계, 분류 코드 후보(IPC·국가과학기술표준분류), 문제 성격(커네빈), 조건부 분석 신호.
- **2단계** 조건부 분석(KT IS/IS NOT·특성요인도·FMEA·JTBD/HMW·생체모방 재검색)은 1차에서 신호만 기록한다.
- **3단계** 규칙(AI 호출 없음): 한 장으로 합침, 발명 원리는 40개 고정 목록으로, 분류 코드는 저장 특허의 실제 코드·KIPRIS 건수로 확인,
  원인이 어긋나면 '확인 필요'. 항목마다 근거 있음(제안문에 있음)/추정(AI 가 채움)을 **규칙이** 판정한다.
- **쓰는 곳** 유추 질의(단별 + 영문 → OpenAlex), 유추 최종 5건(대상어 겹침 → 기능 문장 재순위 → 자료원당 2건 우선·모자라면 순위대로),
  모순 → novel 갈래 장벽·과제명(차별화 갈래는 카드 저장만), 분류 코드 → KIPRIS 분류 검색, 원인·추정 → 보완 질문.
- **사용자 수정 우선** 고친 항목은 AI 가 덮어쓰지 않고(ADR 0054 와 같은 원칙), 그 항목에 기대는 것만 다시 계산한다. 과제안은 자동으로
  다시 만들지 않는다 — 버튼.
- **누적 학습** 모델 학습 없음. 수정 짝을 저장하고 1차는 **본인** 수정만 다음 진단의 예시로 쓴다(아이디어 유출 방지). 공용 계정 수정은
  저장하지 않는다. 표현 다듬기(의미 유사도 ≥ 0.95)·시험 계정 줄은 뺀다. 사전 후보·관리자 통계·다른 사용자에게 일반화하는 방식은 2차.
- **안전망** `config/problem_card.yaml enabled` 기본 꺼짐. 카드는 `ProposalRequest.problem_card`(선택)로만 다니고 `search_text`·
  `prompt_view`·캐시 키에 들어가지 않는다 — 카드가 없거나 늦거나 실패하면 모든 단계가 종전 방식이다.
- 골든셋·반복 평가는 하지 않는다(2026-11-09 방침). 스위치는 4사례 실제 AI 카드를 소유자가 본 뒤에 켠다.

## 결과
- 좋은 점: 대상어가 겹치는 자료만 유추에 남고, 영문 질의가 항상 생기며, 과제명 이유에 발명 원리가 붙는다. 카드가 화면에 보여 틀린 진단을
  제안자가 바로 고친다.
- 비용: ① AI 호출 +1(작은 호출 중앙값 약 6초 — 뒤에서 실행), 국문 기능 문장 수정 때 +1, novel 갈래 유추 +4~6초(질의 4개·재순위).
- 남은 것(2차): 조건부 분석 실행, 장소어·동의어·기능 문장↔IPC 후보 파일과 승인 절차, 관리자 통계·403 규칙, 다른 사용자 수정의 일반화,
  공식 코드표(`verify.code_table`).
