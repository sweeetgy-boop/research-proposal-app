# ADR 0013 — 초안 품질 강화 8가지는 측정 뒤 효과가 확인된 것만 기본 켬 (2026-10-27)

**배경** 입력 보강 질문, 섹션 설계도, 섹션별 맞춤 검색, 채택 과제 본보기, Argon 보완 작성, 규칙 검사 선행, 핵심 섹션 두 후보, reranker — 모두 그럴듯하지만 각각 시간·호출·복잡도를 더한다.
**선택지** (a) 전부 켬, (b) 전부 설정만 두고 끔, (c) `config/pipeline.yaml` 로 켜고 끄되 기준·모두 켬·빼기 실험으로 측정해 효과 있는 것만 기본 켬.
**결정** (c). 결정 규칙: 점수·지표를 떨어뜨리지 않고 한 가지 이상 개선한 항목만 켠다. 생성 시간이 기준의 2배를 넘으면 시간이 큰 항목부터 끈다. reranker 는 precheck 적중률 유지·무관 근거 감소·지연 2초 이내일 때만.
**이유** Argon 점수는 run 간 편차(±1)가 있어 로컬 지표(알림 수·필수 요소 충족·근거 관련도)를 우선하고 Gemini 호출 상한(120/밤)을 지킨다.
**결과** [Q] 브랜치 feat/draft-quality, 결과는 `docs/eval-2026-10-27.md`. 항목별 결정은 이 문서 뒤에 ADR 로 덧붙인다.
