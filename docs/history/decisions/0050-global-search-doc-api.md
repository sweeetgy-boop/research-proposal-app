# ADR 0050 — 위쪽 통합 검색(⌘K/Ctrl+K)과 문서 단위 검색 API (2026-10-29, [UI] 레인 3, #105)

## 맥락
Research Studio 화면은 "자료 검색" 메뉴를 없애고, 위쪽 검색창 하나로 내 제안서와 수집 자료를 함께 찾는다.
기존 `/v1/search` 는 청크 단위다. 그래서 제목·자료원·연도·원문 링크를 보일 수 없고, 같은 문서가 여러 줄로 나온다.
또 공용 계정에는 internal 자료가 보이면 안 된다.

## 결정
- `GET /v1/search/docs?q=&limit=&sources=&year_from=&year_to=` 를 새로 둔다.
  - 처리 순서: 청크 검색 → 문서마다 첫 청크 → 문서 조회 → 자료원·연도로 거르기.
  - 응답은 표시 정보만 담는다. doc_id 는 키로만 쓰고 화면에 보이지 않는다.
  - 공용 계정은 `PublicOnlyRepository` 를 거친다(저장소를 세션별 서비스로 받기 때문).
- 화면은 combobox/listbox 하나에 두 묶음을 보인다.
  - "내 제안서": 기존 runs 목록에서 제목으로 거른다.
  - "자료": 새 API 의 상위 5건.
  - 키보드 ↑/↓·Enter·Esc, 입력 디바운스 0.25초.
  - [자료 전체 결과 보기]는 자료 검색 화면을 연다(검색 조건이 주소에 담김, 자료원·연도 거르기).
- 로그인 전 검색칸은 **누르거나 입력할 때만** 로그인 창을 연다(#108 수정).
  포커스만으로 열면, Esc 로 닫은 뒤 포커스가 돌아올 때 창이 다시 열렸다.

## 결과
- 자료 검색 화면은 문서 단위가 되었다(유사도 숫자 없음). 청크 API 는 MCP 와 기존 쓰임을 위해 남긴다.
- 연도로 거르면 연도를 모르는 자료는 빠진다.
- 자료 현황 화면(옛 "자료원 상태")은 자료원 한국어 이름·건수·마지막 적재만 보인다.
- 근거: `docs/status.d/feat-ui-studio-search.md`.
