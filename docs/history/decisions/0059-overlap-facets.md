# ADR 0059 — 유사과제 고도화 1단계: 4축 분해·IDF 가중·동의어 확장은 기능 스위치 뒤에서, 차단 규칙은 유지 (2026-11-09 초안, chore/wave-1109-contracts)

## 배경
- ② 유사과제 판정은 e5 후보 풀 → reranker ≥ 0.5 + 핵심어 ≥ 1 규칙 → Argon 같음 판정(대상·문제·방법) 순이다(ADR 0004·0028·0039).
- 시범 운영에서 두 방향의 오류가 남아 있다. (가) 흔한 단어(철도역·열차·안전 …)가 겹쳐 무관한 과제가 핵심어 조건을 넘는다 —
  `generic_terms` 를 손으로 늘려 막아 왔다(현재 110개 안팎). (나) 같은 뜻을 다른 말로 쓴 과제(궤도틀림/궤도 불규칙, 전차선/가선)를 놓친다.
- Argon 판정은 "같다/부분/다르다" 한 값이라 **무엇이** 같은지(대상인가 방법인가)를 화면에서 알 수 없다.
- 한 번에 바꾸면 어떤 변화가 효과였는지 알 수 없고, 평가 체계(ADR 0058)가 아직 없다.

## 선택지
1. generic_terms 를 계속 손으로 늘린다 — 거짓 양성마다 사후 대응, 끝이 없다.
2. **4축 분해(target·problem·method·place) + 말뭉치 IDF 가중 + 동의어 확장을 각각 기능 스위치 뒤에 넣고, 기본은 모두 끔.**
   판정 출력에 축별 겹침(0·1·2)을 더해 화면에 보이되 차단 규칙은 지금 그대로. 켜는 결정은 L1 비교 평가(같은 seed) 뒤.
3. 임베딩 모델 교체·재색인 — 비용 크고 사내 자료 재적재가 필요, 효과 예측 어려움.

## 결정
2 를 택한다.
- 스위치 `config/overlap.yaml facets.enabled`·`idf_weighting.enabled`·`synonyms.enabled`(기본 false). **false 면 결과는 지금과 같다** — 회귀 시험으로 확인.
- 4축 분해는 로컬 모델 우선(판정 전 단계라 외부 전송을 늘리지 않음), 실패하면 규칙 사전. 축별 질의로 검색해 RRF 로 합치고, 풀·reranker 입력 수는 종전과 같다.
- Argon·로컬 같음 판정 출력에 `facet_overlap` {축: 0|1|2} 를 더한다(없어도 됨). `OverlapAlert.facet_overlap` 로 화면·REST 에 보인다.
  **차단은 지금 규칙(reranker + 핵심어 + Argon same) 유지.** "4축 모두 높을 때만 차단"으로 바꾸는 것은 평가 결과를 보고 따로 결정한다.
- IDF 는 적재·재색인 때 계산해 캐시(`data/cache/idf.json`), 없으면 가중 없음.
- 동의어 후보는 `rra terms candidates` 결과를 빈도·공출현으로 자동 선별해 `docs/review/terms-review.md` 검토표로 만들고, 고신뢰만 `overlap.yaml`
  후보 구역에 둔다. **사람 검토 전에는 운영 스위치를 켜지 않는다**(ADR 0022 "보수적 규칙 + 사람 승인" 연장).
- 운영에서 켜는 조건: L1 비교(가 main / 나 레인 A 적용 / 다 스위치 on)에서 `recall_at5` 가 떨어지지 않고 `false_block` 이 늘지 않음
  + 동의어는 사용자가 검토표를 확인. 조건 전에는 off 로 배포만.
- 계약: `docs/contracts/overlap-facets.md`, 모델 `domain/models/facets.py`.

## 이유
- 스위치 뒤에 두면 레인 E 를 다른 레인과 같이 합치고 배포해도 운영 동작이 바뀌지 않는다.
- 축별 겹침을 먼저 "보이기만" 하면 차단 규칙을 바꾸기 전에 사람이 패턴을 확인할 수 있다(정책 근거 팝업·[유사함] 선택과 같은 방식).
- IDF 는 generic_terms 손질을 자동화하는 가장 작은 변화다.

## 결과
- 좋은 점: 검색·판정 변화를 한 가지씩 켜고 평가할 수 있다. 화면에 "무엇이 같은가"가 보인다.
- 비용: 분해 로컬 호출 1회(precheck 지연 +수 초, 켤 때만), IDF 캐시 파일, 검토표 작성.
- 남은 것: 차단 규칙 변경 여부(4축 모두 높을 때만) · 동의어 2단계(차단 키워드 겹침에도 적용) · 임계치 재측정.
- 상태: **확정(2026-11-09 저녁)** — 레인 E 구현(ADR 0064, #138)·연습용 묶음 40문제 짝 비교(`docs/eval-2026-11-09-compare.md`): facets+idf 는 종전과 차이 없음(McNemar, 갈린 7문제 3회 재측정 동일), idf 만은 함정 1건 덜 차단·역방향 영향 없음. 운영은 세 스위치 off 로 배포. 같은 날 밤 방침 변경(평가 보류 — 문제가 생기면 그때 고침)으로 **세 스위치 모두 off 유지** — 검증 없이 켜 두면 중복을 놓쳐도 드러나지 않는다. 코드·스위치는 남겨 두고 필요할 때 재개.
