# ADR 0010 — 근거 출처 다양성, 자료원별 최소 보장 6 (2026-10-26, PR #18)

**배경** OpenAlex 2,482건 적재 뒤 골든셋 01 의 근거 20건에 영어 논문이 0건(상위 160 안에 4건).
**선택지** (a) 임계치·k 조정, (b) 자료원별 검색 분리 + 최소 보장, (c) reranker.
**결정** (b): 넓은 검색(k×4) → 하한 통과가 min_per_source 미만인 자료원만 `hybrid_search(sources=[…])` 재검색 → `balance_sources`(초과 시 라운드 로빈). 값은 6.
**이유** 4 에서는 논문이 근거 집합에 있어도 7B 가 인용하지 않았고(0건) 6 에서 인용 6건. 8 은 보장분 합이 k 를 넘어 잘림(라운드 로빈으로 고침). reranker 는 [Q] Q8 에서 측정.
**결과** 01 alio 9/own 6/openalex 6, 02 alio 7/own 7/openalex 6. Argon 점수는 run 간 편차 안(3/2/2/3 → 3/2/3/3). 근거 `408cd60`~`f791569`, architecture §4.13.
