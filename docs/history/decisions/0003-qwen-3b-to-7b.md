# ADR 0003 — 로컬 작성 모델 Qwen2.5-3B → 7B (2026-10-13)

**배경** 3B 가 섹션 JSON 형식을 지키지 못해 파싱 실패가 잦았다(대화 기록 기준, 미검증 — 커밋 "7B 전환 보정" 으로 간접 확인).
**선택지** (a) 3B + 더 엄격한 프롬프트, (b) 7B 4bit, (c) 외부 API 로 작성.
**결정** (b). 32GB Mac mini 에서 mlx 4bit 7B 가 돈다. 외부 API 는 검토에만(ADR 0007).
**이유** 형식 이행이 먼저. 7B 가 새로 만드는 문제(본문 속 자료 태그 조각, 지어낸 수치, 한자 혼입)는 규칙(`llm_output`·`numbers`·`foreign_script`)으로 잡는다.
**결과** 2026-10-26 벤치 JSON (b) 96.5%, 섹션당 6~7초. 근거 `e5c59b5`, `ba3e600`, llm-bench.
