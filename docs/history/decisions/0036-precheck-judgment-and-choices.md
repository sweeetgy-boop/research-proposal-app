# ADR 0036 (레인 A) — ② 유사과제 판정: reranker 점수 중심 + AI 같음 판정 + 제안자 선택 (2026-10-28)

## 배경
시범 운영에서 "폐철도역사 유휴 공간 활용" 아이디어가 "철도 산업 발전을 위한 해외 철도차량 조달정책 분석"·"철도 터널내 바닥
여굴 채움재…" 에 차단됐다. 공유 키워드가 "부족·정책·상황·인식·필요한" 같은 일반어였고, e5 코사인은 철도 문서끼리 0.83~0.90 에
몰려 무관한 과제도 own 임계치 0.80 을 넘는다. 차단된 엉뚱한 과제가 그대로 활용·차별화 제안·비교표·과제 추천의 입력이 되어
제안까지 엉뚱했고, 추천은 "검증에서 제외됨 2건" 으로 0건이 됐다.

## 선택지
1. 일반어 목록만 늘린다 — 서술어는 끝이 없고 e5 점수 문제는 그대로.
2. e5 임계치를 올린다 — 같은 과제(0.84~0.86)도 같이 떨어진다(골든셋 01·10).
3. **reranker 점수를 주 점수로, 상위 10건은 AI 가 "대상·문제·방법이 같은가" 판정, 마지막은 제안자 선택** — 규칙·AI·사람 세 겹.

## 결정
3 을 택한다.
- 규칙(`domain/rules/overlap.judge`): reranker(bge-reranker-v2-m3, 0~1) 점수가 있으면 `overlap.yaml rerank.threshold`(0.5) 이상
  AND 아이디어 핵심어(실시간 검색과 같은 Argon 키워드, 없으면 규칙 키워드) 중 문서에 있는 것 `keywords.core_min_hits`(1) 이상.
  e5 는 후보 검색에만. 일반어에 시범 서술어·명사 40여 개 + `응용연구`(사내 기록 서식어) 추가. 같은 제목 행은 한 행(`merged_ids`).
- AI 같음 판정(`usecases/judge_sameness.SameJudge`): 상위 10건을 Argon 한 번에 → same 만 차단, partial(일부 겹침)·different 는
  차단하지 않는다. 행마다 한 줄 이유. Argon 실패(예외·40초·예산·해석 실패) → 로컬 모델(로컬 슬롯 안) → 규칙 판정 + 화면
  "AI 판정 실패 — 규칙 기준" + [다시 시도](`POST /v1/precheck/judgment`). include_internal=false 면 internal 문서는 Argon 에 안 보낸다.
  결과는 입력 글 해시로 30분 메모 — 비교표·제안·생성 게이트가 같은 판정을 쓰고 LLM 을 다시 부르지 않는다. 추천의 자기 중복
  검사 같은 내부 호출(`__call__`)은 메모가 없으면 규칙만.
- 제안자 선택: 행마다 [유사함]/[관련 없음] → `ProposalRequest.similar_choices`(doc_id·선택만). [유사함] 행만 비교표·활용 제안·
  차별화 과제안·③ 5. 특이사항 차별성 문장에 쓴다. 차단 행을 모두 [관련 없음] 으로 고르면 차단 해제(생성 게이트도). 선택은
  `data/feedback/similar_choices.jsonl` 에 doc_id·선택·점수·판정·아이디어 해시만 남겨 임계치 조정에 쓴다.
- 과제안: 추천 카드에 연구목표·연구방법·적용범위(`ProjectRecommendation.goal·method·scope`, `ProposalRequest.method·scope`).
  핵심 칸(가제·요약·차별점)만 엄격 검사, 나머지 칸은 걸린 칸만 비우고 범위 밖 id 는 목록에서만 뺀다. 검증 뒤 2건 미만이면 제외
  사유를 주고 한 번 다시 받는다. [AI로 다듬기]는 한 칸만(Argon → 로컬, 실패면 원래 글 + 사유). 원래·카드·직접 고친 안은
  run 의 `idea_versions.json`.

## 결과
- 골든셋 측정(docs/eval-2026-10-28-precheck-v2.md): 상위 5 적중 기준 유지, 거짓 차단 0, AI 판정은 차단을 "같은 과제" 로 좁힌다.
- ② 지연은 AI 판정만큼 늘지만 과제안 생성과 동시에 돌려 체감은 둘 중 긴 쪽.
- 한계: 판정은 Argon 의 의견이다 — 화면에 "판단"·이유를 보이고 최종 선택은 제안자. 로컬 대체(7B)는 시범 측정 안 함(운영 mlx 사용 중).
