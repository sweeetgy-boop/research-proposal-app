# ADR 0048 — 화면 안 로그인과 왼쪽 사이드바 화면 틀 (Research Studio) (2026-10-29, [UI] 레인 1, #102·#106)

## 맥락
시범 의견: 로그인 페이지가 따로 있어 첫 화면이 빈 로그인 카드였다. 위쪽 메뉴로는 6단계 흐름과 제안서 목록을 함께 보기 어려웠다.
그래서 동료 UI 캡처("Research Studio")의 틀을 따르기로 했다.

## 결정
- 로그인 페이지를 없앤다.
  - 보호 화면(`/new`·`/runs`·제안서 주소·자료 검색·자료 현황)은 **주소를 그대로 둔 채** 그 자리에 로그인 창을 띄운다. 창은 앱 전체에 `LoginDialogProvider` 하나다.
  - 로그인하면 같은 화면이 그려진다.
  - 홈·작성 가이드는 로그인 없이 열린다. 옛 `/login` 주소는 홈과 로그인 창을 연다.
- 화면 틀은 왼쪽 사이드바 + 위쪽 막대다.
  - 사이드바: "R" 타일 + "Research Studio", 메뉴 연구 작업실·새 제안서·내 제안서(건수)·작성 가이드. 아래쪽에 자료 현황·저장 안내·사용자 칸·테마.
  - 위쪽 막대: 경로 표시 `Research Studio › …`, 통합 검색, 작성 가이드.
  - 1024px 미만은 사이드바 대신 접는 메뉴(native `<dialog>`).
- 저장 안내는 "제안서는 연구원 서버에 저장됩니다."이다. 공용 계정에는 "공용 계정의 제안서는 함께 쓰는 사람에게 보입니다."를 덧붙인다.

## 결과
- 로그인 전에도 앱 틀과 홈이 보인다. 개인 데이터와 API 호출은 로그인 뒤에만 있다. 세션 쿠키·CSRF·잠금 규칙은 그대로다.
- 메뉴 항목은 `components/frame/Sidebar.tsx`, 경로 이름은 `frame/crumbs.ts` 한 곳에서 정한다. e2e 로그인 도우미는 `/new` 를 연 뒤 창에서 로그인한다.
- 내 제안서 건수는 기존 `GET /v1/runs?limit=50` 의 길이다. 50건을 넘는 사용자가 생기면 total 필드를 검토한다.
- 근거: `docs/status.d/feat-ui-studio-frame.md`.
