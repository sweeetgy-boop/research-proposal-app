# ADR 0005 — 생성 근거 관련도 하한 0.79 (2026-10-26, 이슈 #2)

**배경** hybrid_search 는 질의와 무관해도 k 개를 채워 도서관(무관) 입력에도 궤도 논문을 인용했다.
**선택지** (a) k 축소, (b) 코사인 하한, (c) 하한 + 한글 청크 키워드 조건.
**결정** (c): 코사인 ≥ 0.79, 한글 청크는 질의 키워드 ≥ 1(영어 청크는 키워드 조건 없음). 통과 0 이면 근거 필수 섹션 빈칸 + 경고.
**이유** 골든셋 01(관련 논문 최저 0.793)·03(무관 최고 0.783) 측정값 사이. 테스트가 측정값으로 고정.
**결과** 03 인용 0건, 01 관련 논문 16건 유지. 근거 PR #4, `tests/fixtures/relevance_golden.json`.
