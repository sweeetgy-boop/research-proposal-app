# ADR 0004 — 유사과제 차단 = 유사도 AND 공유 키워드 (2026-10-13)

**배경** e5 코사인만으로는 무관한 한국어 문서도 own 임계치 0.80 을 넘어 거짓 양성 차단이 났다.
**선택지** (a) 임계치 상향, (b) reranker, (c) 공유 키워드(일반어 제외) 조건 추가.
**결정** (c), 키워드 2개 이상. 임계치는 표본이 쌓인 뒤 조정, reranker 는 후속(이슈 #12).
**이유** 즉시 적용 가능하고 설명 가능(겹친 키워드를 알림에 표시).
**결과** 골든셋 01·02 의 거짓 차단이 줄고 진짜 차단은 유지(P0~P7 판단 A: 차단 01 6→5, 02 3→2). 근거 `70dad36`, `config/overlap.yaml`.
