# ADR 0016 — 웹 이미지 판독: OCR 대조 없는 수치는 근거가 아니다, 해시 캐시(실패 포함), 공용 Gemini 제한기 (2026-10-27)

**배경** 한국철도공사 누리집의 경영목표·전략체계·통계는 상당 부분이 이미지(체계도·표·그래프)다. 본문 크롤만으로는
정책 근거(2-가-(3) 전략과제 연계 등)가 비고, 이미지를 LLM 에 읽히면 숫자를 지어낼 위험이 있다(§4.11 수치 정책).
비용·속도 제약: Gemini 호출은 통합 세션 큐로 제한되고, 같은 이미지를 두 번 보낼 이유가 없다.
**선택지** (a) Argon 판독만 믿고 적재, (b) macOS Vision OCR 만(구조 없음), (c) OCR 을 대조용으로 두고 Argon 판독의 수치는
OCR 에도 있을 때만 인정, 나머지는 "판독 확인 필요" 로 표시. 캐시는 (1) 성공만, (2) 실패 포함. 제한기는 (i) 호출마다 새로, (ii) provider 당 공유.
**결정** (c)+(2)+(ii). 이미지 1건 = 문서 1건(`text_basis="image_vision"`, `raw.image` 에 원본 링크·종류·미확인 수치), 페이지 본문이
이미지 텍스트와 겹치면 본문이 이긴다. OCR 이 없으면(리눅스·ocrmac 미설치) 파이프라인은 계속하되 모든 수치가 미확인이다.
Argon 실패·JSON 아님은 OCR 텍스트만 적재하고 실패도 해시로 캐시한다(다시 부르려면 캐시 파일 삭제). 거르기(로고·배너·아이콘·반복 해시)와
처리 순서(경영목표·전략·비전 > ESG·정책 > 통계 > 보도자료)·상한(기본 2000, 초과는 OCR 만)은 순수 규칙이고 `--dry-run` 이 계획을 먼저 보여 준다.
Gemini 제한기(동시 4·분당 60·429 지수 백오프+Retry-After)는 프로세스 안에서 provider 당 하나를 검토·차별화·추천·판독이 공유한다;
프로세스 간 제한은 통합 세션 큐가 맡는다. 이미지는 PIL 디코딩까지 `_sandbox` 자식(rlimit·타임아웃·RSS 감시·픽셀 상한)에서만 한다.
**이유** 생성 단계의 수치 lint·정책명 grounding 은 그대로 두고, 적재 전에 한 번 더 걸러야 이미지 출처 수치가 "근거" 로 둔갑하지 않는다.
OCR(Vision)은 한국어 인식률이 높지만 구조를 모르고, Argon 은 구조를 읽지만 작은 글자를 어림잡는다 — 둘의 교집합만 수치 근거로 쓴다.
**결과** 코드·fixture 테스트만(실제 스냅샷·Argon 호출은 통합 세션): 새 테스트 83, 계약 8 유지. 실측 지표(구조화 성공률·숫자 대조 통과율·장당 시간)는
`rra vision sample` 이 `docs/ocr-sample/summary.md` 로 낸다.
