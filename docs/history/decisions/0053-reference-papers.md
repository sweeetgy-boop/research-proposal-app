# ADR 0053 — ② 관련 연구(논문)를 참고로 골라 차별화·과제안에 쓰기 + 유사과제 0건이어도 과제안 추천 (2026-11-03, feat/reference-papers) — 초안

## 맥락
- 운영(36e0709)에서 아이디어 "철도역사 비둘기 침입 방지"를 넣었더니, 유사과제 10건을 모두 '다르다'로 판정했다(유사함 0건).
  차별화 과제안은 "추천 0건"과 "기존 과제들과 차별성을 갖는 과제를 추천할 수 없습니다"만 보였다.
- 관련 있는 자료는 ② 관련 연구에 실시간 검색으로 들어온 논문 하나뿐이었다(ScienceON 2025, 도시 비둘기 관련).
  관련 연구에는 선택 단추가 없어서 이 논문을 비교표·활용 제안·과제안으로 넘길 길이 없었다.
- 원인 1: `prompts/recommend.md` 가 "겹치는 과제 없음"도 빈 배열을 내도 되는 사유로 허용했다.
- 원인 2: `RelatedResearchList` 는 목록을 보여 주기만 한다. 논문을 유사과제 판정에서 빼는 결정(ADR 0028)은 그대로 둔다.

## 선택지
1. 논문을 다시 유사과제 후보에 넣는다. ADR 0028 을 되돌리게 되고, 논문 때문에 차단이 생긴다.
2. 관련 연구에서 제안자가 고른 논문만 **참고(reference)** 로 넘긴다. 판정·차단에는 쓰지 않고 비교표·활용 제안·과제안에만 쓴다.
   함께, 겹치는 과제가 없다는 것만으로는 추천을 비우지 않게 프롬프트를 바꾼다.
3. 프롬프트만 고친다. 0건은 줄겠지만 근거로 쓸 자료가 없어서 지어내기 폐기가 늘어난다.

## 결정
2를 택한다. 계약은 `docs/contracts/reference-papers.md` 에 적는다.
- 요청 `ProposalRequest.reference_ids: list[str]` 를 둔다(최대 5, 중복 제거). `FORM_ONLY_FIELDS` 라서 작성 프롬프트에 들어가지 않는다.
  precheck 판정·차단·`similar_choices`·선택 기록에는 쓰지 않는다.
- 비교표 열에 `kind: "similar" | "reference"` 를 둔다. reference 열의 구분은 '선행연구'다.
- 추천과 차별화 응답 형식은 바꾸지 않는다. `compared_with`·`evidence` 에 reference doc_id 를 쓸 수 있다.
  검증 허용 범위는 [유사함] 알림 + 근거 검색 + reference 다.
- `recommend.md`: "겹치는 과제 없음"은 빈 배열 사유가 아니다. 그때는 '새 영역'으로 보고 목적 안에서 1~3건을 낸다.
  빈 배열은 근거가 전혀 없거나 목적 밖일 때만 낸다. 지어내기 금지는 그대로다.
- 유사함 0건인데 추천도 0건이면 '새 영역' 지시를 붙여 1회 다시 요청한다(Argon → 로컬 순서 유지). 이때 `retry_used: true` 다.
  추천이 0건이고 reference 도 없으면 `hint: "reference"` 를 준다. 화면은 이것을 받아 "관련 연구에서 참고 논문을 골라
  [과제안 다시 만들기]"라고 안내한다.
- 차별화 활용 제안은 유사함 0건이어도 reference 가 있으면 실행한다.

## 이유
- ADR 0028(논문은 판정 제외)과 ADR 0036(비교·제안은 사람이 고른 행만)을 함께 지킨다. 사람이 고른 논문만 넘어간다.
- 근거 구획이 생기므로 1~3건을 내라고 요구해도 지어내기 검증(doc_id 범위·수치)을 그대로 쓸 수 있다.
