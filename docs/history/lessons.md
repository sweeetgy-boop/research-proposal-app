| OpenAlex 전체 적재가 401 로 실패 | 2026-10 부터 cursor 페이징에 API 키 필요 | page 페이징(10,000건 상한) + 선택 API 키 | `47279e3` |
| CI 에서 샌드박스 파서가 import 실패 | 리눅스에서 RLIMIT_AS 가 공유 라이브러리 매핑을 막음(pymupdf) | RLIMIT_AS 제거, RLIMIT_DATA + 부모 RSS 감시 유지 | `1d5fa87` |

| 사내 과제 압축본이 DRM 표식으로 보임 | 압축 과정의 표식을 암호화로 오인 | 원본 폴더(878개)는 정상으로 확인 | (대화 기록 기준, 미검증) |
