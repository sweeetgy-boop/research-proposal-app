# 한 장 요약 (2026-10-29 최신화)

**문제.** 철도연구원 연구과제 제안서(별지 제2호서식, 12개 섹션)는 제안자가 유사·중복 과제를 직접 확인하고, 근거를 모으고,
섹션을 쓰고, 양식을 채운다. 사내 과제 1,119건·공시 요약 120건·국가R&D 과제·논문을 매번 다시 찾기 어렵고, 중복 과제는 심사에서 걸린다.

**해결.** 근거 기반 작성 지원 Agent(RRA). 자료 16,100건(공사 홈페이지·논문·NTIS·ScienceON·사내 과제·공시 요약·공고 등)을
SQLite(FTS5 + 벡터, RRF)에 적재하고 ① 아이디어 입력 → ② 유사과제 확인(표 먼저 → Argon 같음 판정 → 제안자 [유사함]/[관련 없음],
같은 연작 한 줄, ScienceON·NTIS·OpenAlex 실시간 검색)·차별화 과제안 → ③ 초안 생성(Argon 섹션 작성 → 규칙 검사 → 로컬 2차 검토,
문장마다 근거 id, 그림은 Nano Banana Pro 로 백그라운드) → ④ 제안자 직접 수정(버전·비교·복원) → ⑤ Argon 최종 검토 1회 → ⑥ HWPX 양식 출력.
흐름 판단은 규칙(LLM 아님), 헥사고날 구조, 보안 규칙 A~J, 외부 전송은 manifest 에 문서 단위로 기록. 로그인은 직원 사번(HMAC)·공용 계정.
