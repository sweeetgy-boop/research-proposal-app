# 예상 질문과 답

**Q. 사내 자료가 외부 LLM 으로 나가지 않나?** (2026-10-29)
2026-10-28 부터 초안은 Argon(Gemini)이 먼저 쓴다(ADR 0032). 보내는 것은 섹션 지시와 검색된 근거 구간이고, 직원 로그인은 public + internal,
공용 계정은 internal 을 빼고 보낸다. 섹션별로 보낸 문서 id·범위가 manifest 에 남고 사람 이름·연락처는 보내지 않는다(ProposerInfo 는 렌더 인자로만).
로컬 모델(Qwen 7B, 127.0.0.1)은 Argon 오류 섹션 대체와 로컬 2차 검토에 쓴다. *(이전 방식: 작성은 로컬만, Argon 은 검토에만 — 10-28 오후까지)*

**Q. 모델이 지어낸 내용은 어떻게 막나?**
근거 id 가 검색 집합 밖이면 문장 폐기, 정책·계획명은 제안자 입력에 있는 것만(grounding), 입력·근거에 없는 수치는 경고 +
검토 지적 의무 + 마무리 점검 맨 위 건수. 검토 LLM 의 수정안·추가 문장도 같은 검증을 통과해야 반영된다.

**Q. 유사과제 판정 정확도는?** (2026-10-29)
후보는 과제형 자료원만(사내·알리오·NTIS 과제·연구용역), reranker ≥ 0.5 + 핵심 키워드 ≥ 1 로 표를 만들고 상위 10건을 Argon 이
"대상·문제·방법이 같은가"로 판정한다. 같은 연작은 한 줄. 골든셋 적중 9/10 + 유사하지 않음 2/2, 무관 차단 0(`docs/eval-2026-10-28-pilot2.md`).
최종 판단은 제안자가 행마다 [유사함]/[관련 없음]으로 한다. *(이전: 유사도(e5) AND 공유 키워드 2개 이상)*

**Q. 비용과 속도는?** (2026-10-29)
초안 1건에 Argon 약 15회, 하루 상한 600회·그림 150장(`config/llm.yaml`·`figures.yaml`). ② 표 약 2초, 초안 글 보임 75초·그림까지 187초
(배포 확인 1건). Argon 응답 중앙 9.1초. *(이전: 로컬 작성 비용 0, 12섹션 105~145초 + Argon 검토 36초)*

**Q. 왜 Streamlit 이 아니라 웹 SPA 인가?**
문장 단위 편집·diff·팝업·접근성(WCAG 2.2 AA, Lighthouse 95)은 SPA 가 맞다(ADR 0008). Streamlit 은 시연·내부용으로 남긴다.
2026-10-29 화면 이름 "Research Studio" — 배포됨 (c277253, 2026-10-29 10:48)(ADR 0048~0051).

**Q. 운영은?**
운영 맥 + launchd(mlx·api·백업·야간 적재·잠들지 않기), 외부는 Tailscale Funnel + 앱 로그인(ADR 0047), 배포는 `tools/deploy.sh`(합쳐도 자동
재시작 없음). 백업은 매일 7벌. Mac mini 이전·고정 IP 는 남은 과제. *(이전: 공개 방식 결정 대기)*

**Q. 양식이 바뀌면?**
run 은 생성 때의 양식 id·섹션 순서를 기억한다. 양식이 바뀌면 이전 run 은 조회만, 재생성은 `--reuse-input`. 템플릿 스크립트는
앵커 불일치로 멈춰 사람이 확인한다.

**Q. 평가 결과가 바뀌면 자동으로 학습하나?**
아니다. 골든셋 피드백 루프는 이슈 #10 으로 남겨 두었고, 임계치·프롬프트 변경은 측정(`rra eval`)과 ADR 을 거친다.
