## 남은 문제

1. **② 유사과제 확인 시간**: 36~76초(중앙 약 43초)로 늘었다. 오후 B 측정은 15.6초였다. 늘어난 것은 AI 같음 판정(상위 10건, Argon 1회)과 자동 과제 추천이 함께 돌기 때문이다(레인 A 측정 AI 판정 중앙 10.7초, 느린 건 35~40초). 배포 기준(생성 시간)에는 들지 않지만 동료가 체감한다. 줄이려면 다음을 검토한다.
   - 판정 제한 40초를 25초로 줄인다.
   - 자동 추천(`llm.yaml recommend.auto`)을 차단일 때만 돌린다.
   - 실시간 검색 대기 15초를 10초로 줄인다.
2. **Argon 응답 지연**: 같은 요청이 보통 10초 안팎인데 가끔 수 분 걸린다(측정 중 다시 쓰기 1회 311초). 읽기 제한 180초·재시도 3회가 그대로 쌓이는 구조다. 다시 쓰기·보완 질문 같은 버튼 기능은 제한을 짧게(예: 45초) 두고 실패 사유와 [다시 시도]를 보이는 편이 낫다(후속).
3. **짧은 입력의 과제 추천**: Argon 이 자료에 없는 정책·계획명을 지어 넣어 규칙에 걸러진다. 다시 받기 지시에 "정책·계획명을 쓰지 말 것"을 더 분명히 넣는 것이 후속이다.
4. **골든셋 정답 목록 보강**: AI 가 "같다"로 막은 정답 밖 과제 2건(영업정지역 활용, NTIS 궤도결함 진단)은 실제 유사과제로 보인다. 사람이 확인해 정답 목록에 넣을지 정한다.
