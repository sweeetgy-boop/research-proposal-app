# 동의어 후보 검토표 (2026-11-09, 레인 E, ADR 0059)

`rra terms review` 가 `config/*.candidates.yaml`(`rra terms candidates` 결과, 미커밋) 을 읽어 자동 선별한 결과다.
**검토 전 — 운영 반영 안 함.** 확인한 항목은 `- [x]` 로 바꾸고, 틀린 묶음은 지운다. 고신뢰 항목은
`config/overlap.yaml synonyms.candidates` 구역에 같은 내용으로 들어 있다. 사람 검토가 끝나기 전에는 `synonyms.enabled` 를 켜지 않는다.

- 읽은 후보 행: 202건 · 묶음: 15건 (고신뢰 2 · 검토 필요 13)
- 고신뢰 = 철도 용어 씨앗 묶음의 구성원이 후보에 둘 이상 나타나고 문서빈도 하한 이상.
- 검토 필요 = 씨앗 구성원이 하나만 나타났거나(공출현 확인 불가), 포함 관계(상·하위어일 수 있음)로 묶인 것.
- 질의 확장은 OR(FTS5 토큰별 인용)로만 쓰고 차단 키워드 겹침에는 쓰지 않는다(1단계).
