# HWPX 줄맞춤·글자 크기 통일 측정 (항목 12, 2026-10-28)

`adapters/rendering/hwpx_format.py` — HWPX 를 만들 때마다(마무리·다시 마무리·`rra runs finalize`·MCP) 단락마다 "있어야 할
서식"을 정해 점검하고, 다르면 고친 뒤 다시 점검한다. 결과(건수만)는 run manifest `hwpx_format` 과 로그 `run.hwpx_format` 에 남는다.

## 1. 무엇이 문제였나 (실물 템플릿 단락 속성 덤프)

- 장·항목·세부·줄표 제목과 본문의 들여쓰기가 **공백 글자**였다(" 가.", "  (1)", "   - ", "    ○ …"). 단락 왼쪽 여백은 0 이라
  두 번째 줄부터는 왼쪽 끝으로 돌아갔다.
- 한 장 안에서 단락 모양이 달랐다: 3장 "가. 경영혁신 측면"(과 그 본문)만 내어쓰기 -1717, 나머지는 0.
- 글자 크기가 섞였다: 5장 특이사항 본문은 제목 단락을 복제해 **13pt 굵게**, 실용화 계획 칸은 10pt, 그림 캡션·출처는 문서 끝
  단락("…연구원장 귀하")의 서식을 물려받아 **17pt 굵게**.
- 활용계획 목록 칸은 한 칸 안에 단락 모양이 3가지(가. -2069, 마. -1600, 나머지 -1300). ("가.만 가운데 13pt" 로 보인 것은
  목록 표를 품은 바깥 단락(가운데 정렬 13pt)의 서식을 칸 안 첫 줄로 읽은 결과다 — 칸 안 글자는 모두 9pt.)

## 2. 단계별 서식 (고친 뒤)

| 단계 | 알아보는 방법(앞 공백 뺀 글) | 왼쪽 여백 | 내어쓰기 | 글자 | 줄 간격 |
|---|---|---|---|---|---|
| 장 제목 | `1. ` | 0 | 1700 | 13pt (양식 그대로) | 160% |
| 항목 | `가. ` | 600 | 1800 | 12pt | 160% |
| 세부 | `(1) ` | 1200 | 2200 | 12pt | 160% |
| 줄표 | `- ` | 1800 | 1100 | 12pt | 160% |
| 본문 ○ (생성 문장) | `○ ` — 부모 단계 + 600 | 장 1200 / 항목 1800 / 세부 2400 | 1800 | 12pt 보통 | 160% |
| 안내 | `※` | 600 | 1500 | 양식 그대로(9·10pt) | 160% |
| 그림·캡션·출처 | 그림 단락, "그림 n. …", 출처 줄 | 0 · 가운데 | 0 | 12pt 보통 | 160% |
| 표 칸(머리표 줄이 있는 칸) | 활용계획 목록·실용화 계획 | 칸마다 모양 하나 — 칸의 원래 모양(가장 많이 쓴 것), ○ 문장이 있으면 칸 첫 단락 모양에 내어쓰기 1.5글자 | | 칸의 원래 크기(9pt·10pt) | 칸 원래(110%) |

- 단위 HWPUNIT(1pt = 100). 공백 들여쓰기 폭을 여백으로 옮겼다(공백 1칸 ≈ 0.5글자 = 600). 내어쓰기 폭은 머리표+공백의 어림값이다.
- 단락 모양은 header.xml 에 복제로 더한다(같은 모양이 있으면 재사용, 실물 템플릿에서 9개). 글자는 넣지 않는다 — 앞 공백 제거와
  `paraPrIDRef`·`charPrIDRef` 변경만. 바뀐 단락의 줄 배치 캐시는 지운다. 결과는 defusedxml 로 다시 파싱한다(보안 F 그대로).
- 제안자 표·서식 번호·제목·맺음말은 점검하지 않는다(양식 그대로).

## 5. 확인하지 못한 것 · 다음

- **한/글 화면 캡처는 없다** — 개발기(macOS)에 한컴오피스가 없어 실제 줄바꿈 위치는 보지 못했다. 단락 속성 표(위)로 대신한다.
  내어쓰기 폭(머리표+공백 어림 1.5글자)은 글꼴에 따라 반 글자 정도 어긋날 수 있다 — Mac mini 한컴오피스에서 시범 HWPX 1건을 열어
  둘째 줄이 머리표 뒤에 맞는지 보고, 어긋나면 `hwpx_format.LEVELS` 의 hang 값만 고친다(구조는 그대로).
- 생성 모드(실물 템플릿이 없을 때의 표 양식)는 단계 단락이 없어 캡션·표 칸·앞 공백만 점검한다.
- 재현: 위 명령. 테스트는 `tests/adapters/test_hwpx_format.py`(실물 닮은 고정 템플릿 `tests/fixtures/hwpx/proposal_form_like.hwpx`,
  `tests/tools/make_form_like_template.py` 로 만든다) — CI 에서도 돈다. 실물 템플릿이 있으면 한 건 더 돈다.
