# 레인 B — feat/edit-ai (2026-10-28, 작성·편집 AI 기능) 전달 사항

## 전달한 것
- **AI 다시 쓰기 0후보 근본 원인 수정** — 정책 근거 없는 2-가-(1) 이 사유 없이 빈 후보를 돌려주던 것 → 사유 코드·한국어
  라벨·[다시 시도]·빈 섹션 "새로 쓰기"·정책 작성안 연결. 다시 쓰기는 Argon 먼저(작성자가 로컬이어도 `rewrite_llm`).
  문구 "Argon 이 같은 지시·근거로 다시 씁니다". 원격·로컬 모두 실패해도 500 대신 사유. ADR 0037.
- **정책적 중요도 작성안 4개** — 방향(정부 계획·공사 전략·감사 지적·현안·지역·사회 정책)별, 근거 문서 겹침 없음, 인용 구간 안에서만
  (정책명·수치 검사), 출처(문서명·연도·쪽·원문 인용·링크). [이 안으로]·합치기·직접 수정+[AI로 다듬기]·[직접 작성]·
  [정책 근거 없음으로 진행]·[다른 안 보기]. 고른 안 → `RunIn.policy_choice` → 원문 재대조(보안 A) → 2-가-(1) 그대로 + 근거.
  "없음" → `policy_basis_needed` 알림("정책 근거 확인 필요") + 제출 전 점검 `policy_basis`.
- **보강 질문 켬** `pipeline.clarify: true`, Argon 먼저, 2~4개(정책 근거·소요예산·연구기간·적용 대상·정량 목표치), 상태 off/enough/failed.
- **보완 질문** Argon 이 본문·근거·작성 지침을 읽고 2~4개(로컬 → 체크리스트), 모든 섹션 체크리스트, [답 반영해 다시 쓰기].
- **새 버전으로 저장** 버튼 항상 켬, "변경 n건" = 서버(마지막 검토 이후 종류별) + 저장 안 한 편집, 변경 없음/있음 팝업 → ⑤ 최종 검토.
- **결함 수정** `decide_evidence` 판단 비교 TypeError(500) — 이미 판단이 있는 문장에 근거 승인을 다시 저장하면 실패하던 것.
- 제출 전 점검 "미해결 알림" 상세가 내부 코드(`input_missing 1건`)를 그대로 보이던 것 → 한국어 라벨.

## 자동 결정
- 2-가-(1) 은 고른 안의 문장을 **그대로** 쓴다(LLM 이 다시 쓰지 않음, origin proposer_input → AI 다시 쓰기에서 보존).
  근거 금지 섹션이지만 원문 대조를 통과한 작성안 구간(`snapshot.policy_ids`)만 근거로 허용(lint 도 같은 예외).
- "정책 근거 확인 필요" 는 양식에 자리표시 문장을 넣지 않고 알림 코드로만 남긴다(제출 파일에 문구가 섞이지 않게).
- 실시간 검색 결과는 ScienceON·NTIS·OpenAlex(논문·과제)라 정책 종류가 아니어서 작성안 후보에 들어가지 않는다. policy_phrases
  의 원문 문장 고르기(pick_quote)를 그대로 쓴다.
- 지역·사회 정책 방향은 앞 세 방향이 쓰지 않은 구간 중 지역·균형발전·교통약자·탄소 등 어휘가 있는 것만("안전"은 너무 넓어 뺌).
- 보완 질문은 Argon 이 "빠진 것 없음" 이라고 답해도 체크리스트 키워드 검사에서 빠진 요소가 있으면 그것을 묻는다.
- 변경 세기 기준은 마지막 최종 검토 버전(없으면 초안 v1·v2 중 최신) — 저장해도 0 으로 돌아가지 않는다("검토 이후 n건").
- run 에서 나중에 고른 정책 근거는 notes 에 두고 AI 다시 쓰기 때 요지(policy_basis)로 얹는다(request.json 은 바꾸지 않음).
- 가짜 모드: 정책 자료 3건(국토부·공사 전략·감사원) 시드, 가짜 LLM 이 보강 질문·작성안·다듬기·보완 질문·전략 정합성에 답한다.
  e2e flow·screens·u9 의 "보강 질문 없음"·저장 뒤 이동 기대값을 새 흐름에 맞춤.

## 남은 일
- 선택형(선택값) 확정 UI 는 웹에 없다(CLI·MCP·REST 만) — 변경 세기는 서버에서 세지만 화면에서 바꿀 곳이 없다(레인 D 판단).
- 그림 [말로 고치기] 거절 메시지에 내부 사유 코드가 괄호로 보인다(`그림을 고치지 못했습니다 (no_change)`) — 레인 C.
- 작성안 방향 분류는 자료원 기준(국토부·공고 = 정부, 공사 = 전략, 감사원·기재부 = 감사)이다. 공사 자료 안의 정부 계획 인용은
  공사 전략으로 묶인다.
