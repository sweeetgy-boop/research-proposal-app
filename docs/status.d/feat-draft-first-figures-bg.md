# feat/draft-first-figures-bg — 초안 글 먼저, 그림은 백그라운드 (2026-10-29, 레인 C, ADR 0045)

- v1 저장 즉시 drafted(초안 글 보임·편집 열림). 그림은 TaskRunner 작업 `<run_id>:figures` 가 run 락·생성 칸 없이 그린다
  (`services/figure_job.py`, 작업 파일 `figures_job.json`·락 `.figures.lock`, 규칙 `domain/rules/figure_job.py`).
- 그림은 한 장씩 도착 → 읽기(`_version`)가 버전에 합치고, 작업이 끝나면 그동안 만든 버전 파일에 한 번 채운다. 그리는 중 편집은 그대로,
  그림 때문에 내용 버전이 생기지 않는다.
- 그리는 자리 동작·그림 추가·[다시 추천]·⑤ 최종 검토·⑥ 마무리는 거부("그림 준비 중 — 끝나면 진행할 수 있습니다." 등 한국어).
- 재시작으로 사라진 작업 → 읽을 때 failed, 자리 실패 카드 + [다시 그리기]. `rra runs active` 가 그리는 run 도 센다.
- 시간 `draft_visible_seconds`·`figures_done_seconds` — RunState·usage·manifest `timing`·GET /v1/runs/{id}.
- 진행 화면: 다 쓴 섹션 먼저 보기(GET /v1/runs/{id}/sections-progress, 읽기 전용). 초안·직접 수정: "그림 준비 중" 자리 카드·한 줄 안내.
- 측정: docs/eval-2026-10-29-draft-first.md.
