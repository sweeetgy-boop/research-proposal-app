# ② 유사과제 확인 v3 측정 — 표 먼저·선택 적용·카드 겹침 재판정 (2026-10-28 밤, 레인 A, ADR 0039)

## 1. 방법
- 골든셋 12건: 기존 10건(`tests/golden/*.yaml`, 정답 `expected_similar`) + 유사하지 않음 2건(`tests/golden/not_similar/`, `must_not_block`).
- 화면과 같은 순서(`tools/eval_precheck_v3.py`): `POST /v1/precheck?stage=rule`(표 먼저) → 곧바로 `POST /v1/precheck/judgment` 와
  `POST /v1/precheck/recommendations` 를 함께. 시간은 모두 ② 시작(표 요청)부터 잰 초.
- 측정 전용 API(포트 8041 — 8021 은 launchd 가 잡고 있어 열 수 없었다), 설정은 작업 폴더 `config/` 사본: `budget.counter` 만
  `llm_budget_laneA.json`, 로컬 모델 주소는 닫힌 포트(시범 mlx 를 부르지 않게 — 오류 응답이면 바로 규칙 기준). 코퍼스·실시간
  검색 캐시는 원 저장소 `data/`(읽기 + 실시간 검색 캐시). 무거운 작업 잠금(`tools/with_heavy_lock.py`) 안에서. 시범 생성 0건 확인 뒤.
- 적중 기준은 v2 와 같다: 상위 5 적중 = 정답 과제가 알림 상위 5 안(정답이 없으면 차단 0), 유사하지 않음은 `must_not_block` 이 차단되지 않음.
  거짓 차단 = 정답 없음(03)·유사하지 않음에서 AI 차단.
- Gemini 호출: 카드 재판정 켬 36회 + 끔(비교) {OFF_CALLS}회 = {TOTAL_CALLS}회(상한 80, 카운터 24 → {COUNTER_END}).

## 6. 남은 것
- 첫 카드까지의 시간은 Argon 추천 응답에 달렸다(51~211초). 표가 먼저 보이므로 막히지 않지만, 카드 영역은 "경과 n초 [취소]" 를 오래 보일 수 있다.
- 카드 다시 받기는 08 에서만 일어났다 — 표본이 적다. 선택 기록이 쌓이면 카드 겹침 하한(규칙 후보 상위 3)·가중치를 다시 본다.
- 가짜 모드 저장소는 reranker 점수를 내지 않아 e2e 는 카드 다시 받기 경로를 지나지 않는다(유스케이스 테스트로 확인).
